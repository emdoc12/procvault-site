# procvault-site

Public website for [ProcVault](https://emdoc12.github.io/procvault-site/) — an
iPhone app for clinicians to log procedures, track ultrasound guidance, and
generate signature-ready attestation PDFs for credentialing.

Served via GitHub Pages. The app itself is closed-source.

- Landing / support: `index.html`
- Privacy policy: `privacy.html`
- Guides: `logging-procedures-for-credentialing.html`, `ultrasound-iv-competency.html`
